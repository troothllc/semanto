# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone taking part in its issues, pull requests and discussions agrees to it.

Report unacceptable behavior to legal@trooth.co. Every report is reviewed, answered and kept confidential. Maintainers may remove, edit or reject comments, commits, code, issues and other contributions that do not follow it, and may ban a participant for behavior they judge harmful.
